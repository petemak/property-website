# Kigali Keys — brand marks

The logo mark: a traditional Rwandan beehive house (the royal-hut form) with a
keyhole doorway and the pointed *agasongero* finial, on a hill line.
Colours: Hill Green `#1F5B4E`, Bone `#FAF7F2`.

## Which file to upload where

| Use | File |
|---|---|
| **Profile picture / avatar / account logo** (Porkbun, GitHub, social, directories) | `kigali-keys-icon-512.png` — square, green tile, transparent-safe. Use `-256` or `-1024` if a size is specified. |
| Site that rejects transparency or wants a photo format | `kigali-keys-icon-512.jpg` (green background baked in) |
| Favicon upload field (some hosts ask for `.ico`) | `favicon.ico` (16/32/48) |
| Logo on a surface the site controls (they place it on their own background) | `kigali-keys-mark-512.png` — the mark only, Hill Green, transparent |
| Anything scalable / print / "vector logo" field | `kigali-keys-icon.svg` or `kigali-keys-mark.svg` |

Most "upload your logo" fields on registrars and directories want a square
image around 200–512px — `kigali-keys-icon-512.png` is the safe default.

## Files

- `kigali-keys-icon.svg` — green tile + hut (master, vector)
- `kigali-keys-icon-{1024,512,256,128}.png` — same, raster, transparent corners
- `kigali-keys-icon-{512,256}.jpg` — same, green background flattened (no transparency)
- `kigali-keys-mark.svg` — hut only, Hill Green, transparent (master, vector)
- `kigali-keys-mark-{1024,512,256,128}.png` — same, raster
- `favicon.ico` — multi-size icon for favicon upload fields

Not included: a horizontal lockup with the "Kigali Keys" wordmark text — ask if
a directory needs that (it needs the Fraunces font rendered in).
